# Fork of the hic mapping pipeline from Arima Genomics implemented as snakemake

Mapping pipeline for data generated using Arima-HiC.



We all love HI-C and we all love snakemake so lets go ahead and put them together. See "Arima_Mapping_UserGuide.pdf (v03)" for a write up on how the pipeline works. At a later date I'll add my own usage instructions for this repo.
